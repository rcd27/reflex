# Адресное слово и пара на выходе

> Дизайн-документ. Замеры датированы 07.09.2026 и верны на эту дату.

## 1. Чем эта работа вызвана

Входной алфавит достроен до полного: `Packet | Opaque | Tick`, всё, что прибывает, — буква одного алфавита. Выхода это не коснулось, и там сегодня двадцать частных словарей без общего закона.

### 1.1. Замер

| что | сколько |
|---|---|
| `type To` в дереве | **44** |
| различных форм среди них | **28** |
| шагов, чей выход имеет форму пары | **1** (`Advancing`: `(Act, Option<Noted>)`) |
| звеньев, чей `From` есть выход другого звена (`SmallVec`) | **1** |
| употреблений `Then`/`.then(` вне `step.rs` | 17 |

### 1.2. Чего этот замер НЕ доказывает

Первая редакция вывела из строки «одно звено ест чужой выход», что остальные сорок три значения словами не являются.

**Вывод неверен, и ошибка методическая.** «Нет потребителя» есть факт о сегодняшней сборке продукта, а не свойство фреймворка. Мы пишем законы, по которым системы будут строиться потом, и замыкаем их пока на себе; отсутствие построенной системы не отменяет права значения быть словом.

Прежняя спека это уже сказала (§3.2): **алфавит входа фиксирован драйвером; алфавит между звеньями задаётся самими звеньями.** Слово определяется позицией и адресом, а не переписью потребителей.

Критерий «нет потребителя» снимается целиком. Он протащил бы в фундамент форму сегодняшнего продукта — ровно то, от чего работа отказалась, отозвав миграцию потребителя из прошлого среза.

### 1.3. Что болит на самом деле

**Показаний нет.** Шаг сообщает, что решил, и не сообщает, чем при этом располагал. Прогон предъявить нечем: чтобы понять, почему звено решило так, приходится читать его состояние — то есть лезть внутрь машины, которую мы объявили значением.

**Складывать наблюдателей нечем.** Докблок `Both` называет цену прямо: *«словарь сигналов общий, поэтому после сложения не видно, кто сказал»*. Два прибора с общим словарём (`Silence` и `Choked` оба говорят «байтов нет») дают неразличимые показания при разном лечении. Лечится сегодня меткой в работе (`Told<S>` с полем `by`), то есть тем, что тип уже знает, но не говорит.

**Пара написана один раз и не обобщена.** `Advancing` отдаёт `(Act, Option<Noted>)` — что сделал и что при этом видел. Это правильная форма, оставшаяся частным случаем.

## 2. Закон: слово адресно

> **СЛОВО ЕСТЬ ЗНАЧЕНИЕ, ОБЪЯВИВШЕЕ СВОЮ ОБЛАСТЬ. Область даёт срок, срок даёт отложимость.**

Три слова, стоящие в дереве, устроены одинаково, и это не совпадение:

| слово | область | срок | что срок значит |
|---|---|---|---|
| `Act` (`Pass`/`Drop`/`Marked`/`Sever`) | пакет | один шаг | ядро держит пакет; ждать нельзя физически |
| `Ordered` (`Nothing`/`Sever`) | разговор | до конца разговора | отложить можно, но не навсегда |
| `Programme` (`Pass`/`Mark`) | цель | до смены плана | откладывается свободно |

```rust
/// ОБЛАСТЬ — то, чему можно велеть или о чём можно судить.
pub trait Region {
    /// Насколько решение об этой области отложимо.
    const DEFERRABLE: Deferrable;
}

/// СЛОВО — значение, адресованное области.
pub trait Word {
    type Of: Region;
}
```

### 2.1. Несущее — адресность, а не наклонение

Первая редакция различала слово и показание по наклонению: слово — императив («сделай»), показание — изъявительное («видел»).

**Проверка пайпом это опровергла.** `Distress::Silence { ms }` изъявителен — он ничего не велит, — но адресован **разговору**: он про этот разговор, а не про мир вообще. У него есть область, из области срок, из срока отложимость. Запрети ему быть словом по наклонению — и прибор тишины окажется обязан слиться с политикой обхода в одну машину, потому что политике нечего есть.

Значит различает не наклонение, а **адрес**:

* **слово** — адресовано области (`Act` → пакету, `Distress` → разговору, `Programme` → цели);
* **показание** — не адресовано **никому**: чем мерили, сколько прошло, что видели по пути.

### 2.2. `()` — слово, адресованное никому

```rust
impl Word for () { type Of = Nobody; }
```

Терминальный объект категории. Звено, которому соседу сказать нечего, объявляет это **типом**, а не пустым вектором в работе: «нечего» видно на подписи, а не после запуска.

### 2.3. Цвет становится проверяемым

Прежняя спека (§7) требовала: *`.async()` на цепочке, производящей `Act`, обязан быть НЕВЫРАЗИМ, а не нежелателен.* Адресность даёт этому механизм — маркер на области, а не перечисление слов:

```rust
/// ОБЛАСТЬ, РЕШЕНИЕ О КОТОРОЙ МОЖНО ОТЛОЖИТЬ.
pub trait CanDefer: Region {}

impl CanDefer for Conversation {}
impl CanDefer for Target {}
// Packet НЕ реализует CanDefer: ядро держит пакет.
```

```rust
chain_producing::<Ordered>().async_lookup(dns);   // законно: разговор терпит
chain_producing::<Act>().async_lookup(dns);       // НЕ СОБИРАЕТСЯ: Act::Of = Packet
```

Запрет живёт в типе области, а не в списке слов. Сетевик, объявивший **свою** область (туннель, интерфейс, сессия поверх миграции), получает ту же защиту, не трогая фундамент.

## 3. Пара

> **Выход шага есть пара: `(слово, показания)`.**

```rust
pub trait Step: Sized {
    type From;
    /// СЛОВО: уходит соседу по стрелке.
    type To: Word;
    /// ПОКАЗАНИЯ: уходят вбок и не читаются никем.
    type Notes;

    fn step(self, input: Self::From) -> (Self, Self::To, Self::Notes);
}
```

Тройка, а не `To = (Word, Notes)`: будь пара одним типом, композиция `B: Step<From = A::To>` заставила бы соседа **есть чужие показания**. Показания обязаны идти вбок, и это должно быть невыразимо иначе, а не оговорено прозой.

### 3.1. Композиция: произведение, а не общий словарь

```rust
impl<A, B> Step for Then<A, B> where A: Step, B: Step<From = A::To> {
    type To    = B::To;
    type Notes = (A::Notes, B::Notes);
}
```

Показания складываются **произведением**: `()` — единица, вложение говорит, кто сказал, **позицией в типе**. Отсюда прямое следствие для `Both`:

```rust
impl<A, B> Step for Both<A, B> {
    type To    = (A::To, B::To);
    type Notes = (A::Notes, B::Notes);
}
```

Названная цена комбинатора снимается **типом**, а не меткой в работе: после сложения видно, кто сказал, потому что позиция и есть имя. `Told<S>` с полем `by` остаётся там, где показания уплощаются на краю в один поток для ленты, — и перестаёт быть единственным способом различить авторов.

**Моноидного трейта не заводится.** Алгебра показаний есть моноидальная структура категории (произведение и единица `()`), а не моноид на одном типе: два показания разных звеньев никогда не сливаются, они становятся парой. Накопление по времени — дело потребителя ленты, а не шага.

### 3.2. Тождество отмечает пустоту

```rust
impl<T: Word> Step for Id<T> {
    type To    = T;
    type Notes = ();
}
```

Тождество обязано быть нейтральным и в показаниях: звено, отмечающее что-либо, соседям не безразлично, а значит тождеством не является. Отсюда же следствие, которое надо назвать вслух: **`Id` живёт только на словах** — объекты этой категории суть слова, и необязательное звено, выключенное настройкой, выражается в той же алгебре, а не особым случаем у вызывающего.

### 3.3. Показания покидают цепочку подъёмом

Функтор подъёма (`over`) — единственное место, где показания выходят наружу:

```rust
impl<S, K: Step> Stream for Over<S, K> {
    type Item = (K::To, K::Notes);
}
```

Внутри цепочки показания никем не читаются (§4.1); за её границей их читает лента, отчёт, расследование. Граница потока и есть граница «вбок».

### 3.4. Комбинаторы показаний не выдумывают

`RMap`, `LMap`, `Contextual`, `Changes`, `Timed`, `By` переименовывают и сужают **слово**; показания они проносят насквозь без изменений. Комбинатор, добавляющий показание от себя, — не комбинатор, а звено, и объявляется звеном.

### 3.5. Показание есть значение, а не рассказ

Правило прежней спеки (§5.3) сохраняется дословно: **показание несёт значения, которыми шаг работал, а не описание их.** `Noted` уже так устроен — несёт `Tick`, `About`, `Naming`, `Sighting`. Значение не может разойтись с собой; строка может.

## 4. Что пара даёт и чего не даёт

### 4.1. Клейсли над Writer: гарантия, а не обещание

Пара помещает шаг в клейслиеву категорию над Writer: слово идёт по стрелке, показание пишется вбок и **никогда не читается**.

Отсюда теорема, а не намерение:

> **Забывание показаний есть функтор `U`, тождественный на объектах и на словах.**

Прогон с показаниями и прогон без них дают побуквенно одни и те же слова. Значит **пара не может изменить ни одного решения** — и это проверяется тестом, а не декларируется докблоком.

Здесь же граница, которую нельзя переходить: как только показание становится **читаемым** следующим шагом (Reader или State вместо Writer), функтор `U` исчезает, поведение начинает зависеть от записанного, и переигровка ломается — молча. Отсюда закон: **показания идут вбок и только вбок.**

### 4.2. Воспроизводимости пара НЕ даёт

Различие, зафиксированное прежней спекой (§5.5) и шестым vision (§8), сохраняется:

| что нужно | чем достигается | нужна ли пара |
|---|---|---|
| **воспроизводимость** — прогнать и получить то же | `S₀` + запись входов | нет |
| **предъявимость** — понять, почему решил так | показания на каждом шаге | **да** |

Шестой vision жёстче и это ограничение обязано быть записано здесь: *«прогнать цепочку дважды самим значит принять её показания за меру её же верности; **цепочка не имеет права сказать, что она видела**»*. Свидетель — независимая запись (`Recording<In>`), прибор иной природы.

**Показания свидетелем не являются и не станут.** Их роль другая и она тоже названа vision'ом (§8.2): когда два прогона одной записи разошлись, переигровка говорит, **что** разошлось, а показания — **на каком шаге**, то есть где сидит скрытый вход, который лечится переносом в алфавит. Без них лечение ищется перебором.

### 4.3. Промежуточные слова теряются, и это выбор

`A` сказала `w₁`, `B` его съела, наружу вышло `w₂`. Что сказала `A`, снаружи не видно.

Отсюда проверяемое правило: **если слово звена важно для расследования, звено обязано отметить его же показанием.** Звено, которое съедает слово и не отмечает ничего, непредъявимо.

## 5. Обязанность полноты

Правило прежней спеки (§5.2) переносится без изменений и распространяется на слово: **выход обязан быть полным относительно того, чего ждут его потребители.** Звено, которое чего-то ждёт, обязано уметь сказать, что этого не будет.

Форма уже стоит в `core/src/disclosure.rs` — решётка по информации:

```text
Awaited  ⊑  Silent  ⊑  Spoken(T)
```

`Silent` есть **наблюдение**, а не приговор. «Не будет» — не элемент решётки, а отдельный факт закрытия: разговор кончился, уточнений больше не придёт.

## 6. Как сортируются двадцать словарей

Правило одно и проверяется двумя вопросами к каждому выходу:

1. **Кому это адресовано?** Есть область (пакет, разговор, цель, объявленная своя) — слово. Нет области — показание.
2. **Что при этом было в руках?** Величины, которыми шаг работал, — показание, независимо от ответа на первый вопрос.

Известное на сегодня:

| значение | адрес | роль |
|---|---|---|
| `Act` | пакет | слово |
| `Ordered` | разговор | слово |
| `Programme` | цель | слово |
| `Distress` | разговор | слово |
| `Sighting` | разговор | слово (проверить: часть вариантов адресована цели) |
| `Noted` | никому | показание |
| `Told<Measured>` (чем мерили: `ms`, `bytes`, `awaiting`) | никому | показание |
| `()` | никому | слово-единица |

Остальные разбираются поимённо на этапе плана, **прогоном, а не грепом**: у значения смотрится, о чём оно говорит, а не как названо.

## 7. Цена, названная заранее

**Тип показаний растёт вложением.** Цепочка из пяти звеньев даёт `((((A, B), C), D), E)`. Тип статичен и при `()` весит ноль байт, но подпись читается тяжело, а уплощение для ленты придётся написать. Уплощение — отдельная работа, и в этот срез оно не входит.

**Горячий путь.** Замер прежней спеки: **3,88 мкс на пакет, из них 238 нс внутри обработчика**; вердикт стоит 6 %, остальные 94 % — дорога в userspace. Форма `Option<Noted>` делает «нечего отметить» одним словом вместо пустого вектора. **Отвергнуто:** обязательный непустой вектор показаний. Проверяется замером до и после на одной записи провода, а не рассуждением.

**Миграция.** 44 места `type To`, четыре крейта. Слово меняет форму у каждого, показания добавляются каждому. Это ломает сборку у всех разом — и это желанная поломка: она заставляет ответить на оба вопроса §6.

## 8. Что сюда НЕ входит

* **Второй этаж** — цепочка, чьим входным алфавитом служит поток показаний предыдущей. Это законный способ дать прибору реагировать на показания другого прибора, и граница этажа — место, где можно записать и переиграть. Строится тогда, когда появится первый настоящий потребитель.
* **Уплощение показаний** в один поток для ленты.
* **Буквы `Taught` и `Commanded`** — внешняя петля и приказ снаружи.
* **Ограничение работы на тик** (`ExpiringSet`, `FlowTable`): остаток обязан быть показанием, но это следствие пары, а не часть её введения.
* **Синтаксис `engine(NFQ) { … }`** и словарь бэкенда через удерживаемые области.
* **Миграция потребителя.** Работа продукта, начинается после и по его решению.

## 9. Открытые вопросы

Критерий опасности прежний: **вопрос есть мина, если ответ меняет подпись, которой уже пользуются многие места.** Безопасен, если меняет тело одной функции или касается непостроенного.

**1. Обязан ли `Step::To` быть ограничен `Word`. МИНА, и она разряжается сейчас.**

Ограничение `type To: Word` — то, ради чего вся работа: оно делает адресность проверяемой компилятором. Но оно же требует, чтобы всякий промежуточный тип объявил область, включая `SmallVec<[Distress; 2]>` (решается `impl Word for SmallVec<[W; N]> where W: Word`, область общая) и включая тестовые заглушки (`u8`, `u32`, `bool` — в тестах, но они тоже стыкуются).

**Решение: ограничение вводится.** Иначе закон остаётся уговором, а тесты — то место, где уговор нарушают первым. Тестовые типы объявляют область явно; там, где области нет по существу, слово есть `()`.

**2. Область `Sighting`. НЕ МИНА: меняет одну реализацию.**

Часть вариантов (`Opened { dst }`, `TargetSpoke { dst }`) несёт адрес цели, часть — свойство разговора. Разбирается при сортировке §6; если окажется, что варианты адресованы разным областям, значение делится на два — и это находка, а не препятствие.

**3. Форма `Deferrable`. НЕ МИНА: касается непостроенного.**

Три градации (`Never`, `WithinConversation`, `Freely`) или маркерный трейт `CanDefer` без градаций. Маркер дешевле и достаточен для единственного сегодняшнего запрета (`.async()` на пакетной цепочке); градации понадобятся, когда появится второй запрет. Решается при написании, YAGNI по умолчанию.

**4. Судьба `Told<S>`. НЕ МИНА.**

Метка автора в работе становится не нужна там, где позиция в произведении уже называет автора. Остаётся ли она для уплощения на краю — решается вместе с уплощением, которое в срез не входит.

## 10. Приёмка

| что | до | после |
|---|---|---|
| шагов с выходом-парой | **1** | все |
| `type To`, не объявивших области | **44** | **0** |
| «кто сказал» после `Both` | метка в работе | **позиция в типе** |
| `.async()` на пакетной цепочке | нежелателен | **не собирается** |
| прогон с показаниями против прогона без | не сравнивался | **побуквенно равны словами** (тест) |
| замер горячего пути | — | **до и после на одной записи** |

Плюс общее: прогон воркспейса зелёный, `cargo check` без предупреждений, базы `cargo doc` и `cargo fmt` не ниже прежних.
