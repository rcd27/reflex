# Ключевание: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Связать ключ с областью (расслоение объявлено, но не взято) и построить слово о цели как копредел по слою со свёрткой от потребителя.

**Architecture:** `Base::Fibre` — ключ области — уже объявлен, но никем не читается; `FlowTable<D, K>` уже обобщена по ключу, но ключ ей даёт вызывающий. Работа: замкнуть одно на другое, чтобы ключ не куовался руками, и добавить подъём по слою — оператор, сводящий последние слова разговоров цели поданной потребителем свёрткой.

**Tech Stack:** Rust 2021, существующие `reflex-core` (`Base`, `Word`, `Mealy`, `FlowTable`), `reflex-engine` (`TargetKey`, `Naming`).

**Spec:** `docs/superpowers/specs/2026-09-09-keying-design.md`

## Global Constraints

- **Ключ не пишется потребителем.** Он выводится из области; цепочка, не различающая имени, ключевать именем не может — это должно ловиться компилятором, а не проверкой.
- **Форма наша, содержание потребителя.** Фреймворк называет копредел, не угрозу. Свёртка приходит значением, как автомат в `own(…)`.
- **Слово о цели — наблюдение с возрастом, не знание.** Не судит о годности, не копит историю: хранится последнее слово каждого разговора, а не их череда.
- **Вывод не зависит от порядка и кратности прихода слов.** Кратность гасит хранилище, от свёртки требуется быть функцией множества.
- **Тест обязан уметь упасть** — сломай проверяемое место и убедись, что он краснеет.
- **Константы протокола и семантика ядерных величин — замером, не чтением.**
- Прогон после каждой задачи: `cargo test --workspace`.

### Task 2: Ключ цели — расслоённый

**Files:**
- Modify: `core/src/word.rs:46-48` (`impl Base for Target`)
- Modify: `engine/src/row.rs` (реэкспорт `TargetKey` туда, где его видит `core`, либо перенос типа)
- Test: `core/tests/word.rs`

**Interfaces:**
- Produces: `<Target as Base>::Fibre = TargetKey<Box<str>>`.

`Target::Fibre` сегодня `IpAddr` — это ложь по коду: `engine/src/row.rs` знает `TargetKey { Named | Unnamed }`, потому что имя есть не всегда.

**Осторожно с направлением зависимости:** `TargetKey` живёт в `reflex-engine`, а `Base` — в `reflex-core`, и `core` от `engine` не зависит. Значит тип переезжает в `core` (рядом с областями, которым он служит ключом), а `engine` его реэкспортирует — иначе появится ребро `core → engine`, которого нет и быть не должно.

- [ ] **Step 1: Написать падающий тест**

```rust
/// Ключ цели расслоён: имя, если цепочка его дала, иначе адрес. Плоский `IpAddr` был бы ложью —
/// он утверждает, что имя есть всегда.
#[test]
fn целевой_ключ_несёт_имя_или_адрес() {
    fn key_of<R: Base>(k: R::Fibre) -> R::Fibre { k }
    let named: <Target as Base>::Fibre = TargetKey::Named("rutracker.org".into());
    let unnamed: <Target as Base>::Fibre = TargetKey::Unnamed(Addr(0x0A00_0001));
    assert_ne!(key_of::<Target>(named), key_of::<Target>(unnamed));
}
```

```rust
/// Последнее слово каждого разговора, ключёванное областью-цели. Кратность гасит здесь:
/// повтор заменяет слово, а не множит.
pub struct Layer<Narrow: Base, Wide: Base, W> {
    said: HashMap<Wide::Fibre, HashMap<Narrow::Fibre, W>>,
}
impl<Narrow: Base, Wide: Base, W> Layer<Narrow, Wide, W> {
    pub fn saw(&mut self, wide: Wide::Fibre, narrow: Narrow::Fibre, said: W);
    pub fn forget(&mut self, wide: &Wide::Fibre, narrow: &Narrow::Fibre);
    /// Свести слова слоя поданной свёрткой. Свёртка — функция МНОЖЕСТВА: порядок ей не виден.
    pub fn join<U>(&self, wide: &Wide::Fibre, fold: impl Fn(&[&W]) -> Option<U>) -> Option<U>;
}
```

- [ ] **Step 1: Написать падающие тесты**

```rust
/// Кратность гасит хранилище: повтор разговора заменяет его слово, а не множит.
#[test]
fn повтор_разговора_заменяет_слово_а_не_множит() {
    let mut layer: Layer<Conversation, Target, &str> = Layer::new();
    layer.saw(target(), flow(1), "молчит");
    layer.saw(target(), flow(1), "ответил");
    assert_eq!(layer.join(&target(), |words| Some(words.len())), Some(1));
}

/// Свёртка видит МНОЖЕСТВО: порядок перечисления на вывод не влияет.
#[test]
fn порядок_прихода_не_виден_свёртке() {
    let mut ab: Layer<Conversation, Target, u8> = Layer::new();
    ab.saw(target(), flow(1), 1);
    ab.saw(target(), flow(2), 2);
    let mut ba: Layer<Conversation, Target, u8> = Layer::new();
    ba.saw(target(), flow(2), 2);
    ba.saw(target(), flow(1), 1);
    let sum = |words: &[&u8]| Some(words.iter().copied().sum::<u8>());
    assert_eq!(ab.join(&target(), sum), ba.join(&target(), sum));
}

/// Доля — законная свёртка: как операция она не идемпотентна, но она функция множества,
/// а кратность уже снята хранилищем.
#[test]
fn доля_законная_свёртка() {
    let mut layer: Layer<Conversation, Target, bool> = Layer::new();
    layer.saw(target(), flow(1), true);
    layer.saw(target(), flow(2), false);
    layer.saw(target(), flow(1), true); // повтор того же разговора
    let share = |words: &[&bool]| {
        let silent = words.iter().filter(|w| ***w).count();
        Some(silent * 100 / words.len())
    };
    assert_eq!(layer.join(&target(), share), Some(50), "два разговора, один молчит");
}

/// Пустой слой слова не рождает: сказать о цели нечего, пока о её разговорах не сказано.
#[test]
fn пустой_слой_молчит() {
    let layer: Layer<Conversation, Target, u8> = Layer::new();
    assert_eq!(layer.join(&target(), |w| Some(w.len())), None);
}
```

```rust
/// Потребитель приносит СВЁРТКУ, а не угрозу: фреймворк называет копредел. «Молчат все» и
/// «молчит хоть один» — разные слова о той же цели из тех же наблюдений.
#[test]
fn свёртка_приходит_значением() {
    let words = [(flow(1), Distress::NoBytes), (flow(2), Distress::Silence { ms: 10 })];
    let all_silent = |w: &[&Distress]| w.iter().all(|d| matches!(d, Distress::NoBytes)).then_some(());
    let any_silent = |w: &[&Distress]| w.iter().any(|d| matches!(d, Distress::NoBytes)).then_some(());
    assert_eq!(join_over(&words, all_silent), None, "молчат не все");
    assert_eq!(join_over(&words, any_silent), Some(()), "хоть один молчит");
}
```
