# reflex

[![CI](https://github.com/rcd27/reflex/actions/workflows/ci.yml/badge.svg)](https://github.com/rcd27/reflex/actions/workflows/ci.yml)

**Поведение сети как значение.**

Диагностика сетевых блокировок в реальном времени: движок наблюдает провод, приборы говорят о том,
что видят, а вы решаете, что с этим делать. Всё, что движок наблюдает и говорит, — значения, и
потому воспроизводимо: тот же вход даёт то же слово.

```rust
use reflex::*;

fn main() -> Report {
    engine(Nfqueue::queue(200))          // носитель — голова цепочки
        .from(Tcp)                       // транспорт: свой словарь провода, свой порт
        .extract(Sni)                    // чем ключуется цель
        .detect(Retransmit::unanswered())// быстрое подозрение — повтор клиента (~300мс)
        .detect(Silence::after(secs(5))) // медленное подтверждение — окно тишины
        .on(|target, distress| match distress {
            // повтор клиента: цель не ответила на просьбу
            Distress::Retransmit { after_ms } => {
                report!("подозрение на тихий дроп: {target} (повтор через {after_ms}мс)")
            }
            // соединение открыто, байтов вниз нет
            Distress::NoBytes => report!("подтверждено: {target} не ответил вовсе"),
            // SYN ушёл, рукопожатия не было — блок по адресу
            Distress::Blackhole { after_ms } => {
                report!("{target}: соединения не было ({after_ms}мс)")
            }
            // по нашим битам марки писал другой агент — находка, не беда
            Distress::Diverged { theirs } => report!("на машине есть кто-то ещё: 0x{theirs:08X}"),
            _ => {}
        })
        .run()
}
```

Это `examples/detect-silent-drop` — он ловит тихий дроп на живом трафике через реальный ТСПУ, а не
на синтетическом цензоре. Тот же код стоит доктестом в шапке `reflex/src/lib.rs`, то есть
проверяется компилятором: витрина не может разойтись с кодом молча.

## Что он умеет сегодня

| прибор | предмет | по чему судит |
|---|---|---|
| `Retransmit` | клиент повторил просьбу, цель не ответила | RTO клиентского ядра, не наш порог |
| `Silence` | разговор открыт, ответа нет | окно тишины и возраст потока |
| `SynDrop` | `SYN` ушёл, рукопожатия нет | возраст потока с открытия |
| `DnsPoison` | на запрос пришёл инжект вместо адреса | `NXDOMAIN` либо пустой ответ |

Свой прибор встаёт в ту же дверь (`own`) и **говорит своим словом** — парк вкладывается в ваш
словарь, а не наоборот. Пример: `examples/bring-your-own-detector`.

Реакция бывает двух родов: `.on` — наблюдать, `.act` — действовать (например, оборвать тихий дроп
`RST`ом за ~300мс вместо вечной крутилки, `examples/sever-silent-drop`).

## Чем он отличается

**Прибор — машина Мили, а не колбэк.** Состояние возвращается значением, а не мутируется: машину
можно скопировать, переиграть и сравнить два прогона.

**Время — буква входа, а не сервис.** Пакет и узел сетки приходят одним потоком, и приборы простоя
видят свой предмет тем же способом, что приборы трафика. Скрытых часов нет.

**Незнание обитаемо.** «Не наблюдал» отделено от «наблюдал пустоту» на всех уровнях: у прибора, у
драйвера, у отчёта. Собственная слепота движка не становится уликой против сети — это отдельный
закон, оплаченный починкой пяти приборов и двух операторов ядра, каждая с замером.

**Носитель — параметр.** `engine(X)` называет носителя; всё ниже первой строки от него не зависит.
Фасад собирается под `x86_64-pc-windows-msvc`; поддержка WinDivert — скелет, не поставка.

**Сценарий — тоже носитель.** Живой провод требует прав и ядра, запись — снятой записи, а
пользовательскую историю надо СОЧИНИТЬ: «клиент попросил, цель смолчала шесть секунд, клиент
повторил». `reflex::scenario::Paper` — тот же `IntoCarrier`, та же цепочка, что пойдёт в бой; часы
двигаются скачком, и шесть секунд истории проходят за микросекунды прогона. Витрина у него —
доктест, который БЕЖИТ.

**Запись — такой же носитель, а не режим отладки.**

```rust
reflex::pcap("capture.pcap").from(Tcp).extract(Sni).detect(Silence::after(secs(5))).on(…).run()
```

Ниже первой строки — тот же код, что на живой очереди. Время идёт из штампов файла (§8), поэтому
окно тишины в пять секунд проходит за микросекунды, а один файл даёт один ответ — живой провод
повторимости не обещает. Чего запись не может, говорит компилятор: `CanSever`/`CanInject` у неё
нет, и `.act(…)` с ней **не собирается**. Диагностика уезжает туда, где нет ни прав, ни сети:
`examples/replay-recording`.

## Предъявимость

Движок умеет доказывать, что воспроизводим: `.certifying()` пишет окно наблюдений и переигрывает
его дважды, сверяя сказанное. Расхождение называется по имени — «неустойчиво», «свидетельства
нет», «воспроизведено». Лента несёт не байты, а буквы входа с адресом: переигрывается то, что
машина видела, а не то, что было в проводе.

## Стенды

Шесть боевых стендов в `examples/*/lab/` гоняют движок на **реальном** трафике через настоящий
ТСПУ, а не через синтетический цензор. Урок, за который заплачено: синтетическая цензура
детерминирована, настоящая — нет, и прибор, поверенный против выдуманной модели, согласен с нами,
а не с миром.

```sh
sudo sh examples/detect-silent-drop/lab/verify.sh
```

Стенд `detect-dns-poisoning` краснеет, когда провайдер не травит домен, — он мерит МИР, а не нас, и
в этом его ценность.

## Требования

Linux с `nfnetlink_queue` и `nf_tables`, root (или `CAP_NET_ADMIN`), conntrack с включёнными
`nf_conntrack_acct` и `nf_conntrack_timestamp` — без учёта движок не поднимется и скажет об этом, а
не соврёт нулями.

## Устройство

`core` — алфавит, машина, шов времени, предъявимость · `instrument` — парк приборов ·
`linux` — носители (NFQUEUE, conntrack) · `reflex` — фасад, единственная публичная дверь ·
`examples` — примеры и боевые стенды.

## Основание

`docs/vision/2026-09-08-reflex-one-machine-vision.md` — почему устроено именно так: один объект
(машина Мили как коалгебра) и двенадцать разделов, выведенных из него. Документ отвечает на вопрос
«почему устроено так», а не «что сделано».

Чем держится каждый закон — типом, тестом или только прозой — проставлено пока у части: обещания
имён держит компилятор (`deny(rustdoc::broken_intra_doc_links)`), у нескольких законов стоят
сторожа, остальное держится прозой. Это работа в ходу, и здесь она названа, а не обещана.

Дельты, ждущие гейта хранителя мат.модели, — `docs/vision/2026-09-10-deltas-pending-gate.md`;
названная дыра, которой кода ещё НЕТ (контур не замкнут: выход шага не влияет на следующий вход) —
`docs/vision/2026-09-10-feedback-and-enrichment.md`.
